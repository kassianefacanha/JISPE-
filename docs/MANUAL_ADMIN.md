# Manual do Administrador

## Login

Acesse o painel administrativo com a conta:

- E-mail: admin@jispe.com
- Senha: jispe@2026

## Funções principais

1. Aprovar ou rejeitar entidades
2. Acompanhar cadastros pendentes
3. Visualizar atletas cadastrados
4. Exportar relatórios em Excel
5. Validar status de inscrições

## Regras

- Entidades precisam estar aprovadas antes do login
- Atenção à categoria por idade e ao uso de CPF único por entidade
- Revisão documental deve ocorrer antes da aprovação final
